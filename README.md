# n3wth/skills

Catalog of AI coding assistant skills for Cursor, Claude Code, Codex, and Antigravity.

Browse the full catalog: [https://skills.n3wth.com](https://skills.n3wth.com)

## Install

```bash
npx skills add n3wth/skills
```

List skills without installing:

```bash
npx skills add n3wth/skills -l
```

Install all skills globally for Cursor:

```bash
npx skills add n3wth/skills --all -g -a cursor -y
```
